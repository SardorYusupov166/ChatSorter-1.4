# ChatSorter 1.4.3 — Minecraft 1.21.11

Создан **mlpgod** для сервера **MigosMC**. Релиз 1.4.3 исправляет воспроизведение звуков уведомлений, если отдельный системный аудиовыход недоступен.

## Переход к сообщению из поиска

- Нажмите правой кнопкой по найденному сообщению и выберите «Показать в переписке».
- Поиск закроется, откроется вкладка сообщения, а чат прокрутится к нему, показывая соседние сообщения.
- Левые клики по ссылкам и другим интерактивным элементам по-прежнему обрабатывает Minecraft.

## Chat Experience Update

- Повторяющиеся подряд сообщения объединяются в одну запись со счётчиком `×N`. Совпасть должны отправитель, текст и категория. Если отправителя определить нельзя, сообщения не объединяются. Функцию можно отключить.
- История хранится локально отдельно для каждого адреса сервера и при повторном подключении восстанавливается по вкладкам с исходными временными метками. Восстановленные сообщения отмечаются «пред. сессия» и не запускают уведомления повторно.
- В настройках можно включить и отключить объединение повторов и восстановление истории, а также очистить историю текущего сервера.
- Лимит восстановления сообщений (от 50 до 16 384) настраивается перетаскиваемым ползунком.
- Нажмите правой кнопкой по сообщению, чтобы открыть меню: копировать текст, текст с исходным временем, Minecraft-форматирование, ник отправителя, ссылку или техническую информацию. Обычные интерактивные клики левой кнопкой по-прежнему обрабатывает Minecraft.

## Исправление звука уведомлений

- Звуки уведомлений берутся из библиотеки звуков Minecraft, но проигрываются через отдельный системный аудиоканал. Громкость ChatSorter регулируется собственным ползунком и не зависит от игровых уровней громкости Minecraft.
- Если Java не может открыть системный аудиовыход, мод включает резервное воспроизведение через звуковой движок Minecraft.
- Ползунок громкости можно менять нажатием и перетаскиванием с зажатой кнопкой мыши.

## Установка

Minecraft **1.21.11**, Java **21+**, Fabric Loader **0.18.0+**, Fabric API для 1.21.11. Удалите предыдущий JAR ChatSorter из `mods` и добавьте `chatsorter-1.4.3.jar`. Настройки вкладок и тем сохраняются.

Дополнение MigosRules устанавливается отдельно, если оно вам нужно.

## Сборка

JDK **21**, Gradle **9.2.1**: `gradle build`. Результат: `build/libs/chatsorter-1.4.3.jar`. GitHub Actions workflow соберёт JAR и загрузит его как артефакт `ChatSorter-mc1.21.11`.

История хранится в `config/chatsorter/history/` в виде отдельных файлов с хэшированными адресами серверов. Настройки чата и очистка истории находятся в существующем окне настроек ChatSorter, открываемом назначенной клавишей.

## Проверки

Архив исходников и настройки версии проверены. Сборка и запуск Minecraft в этой среде не выполнялись.
